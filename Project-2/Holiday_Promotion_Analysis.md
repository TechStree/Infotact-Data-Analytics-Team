# Holiday and Promotion Analysis

## Distribution

| Holiday/Promotion Status     | Count |
| ---------------------------- | ----: |
| No Holiday/Promotion (0)     | 36747 |
| Holiday/Promotion Active (1) | 36353 |

## Findings

* The dataset contains 36,747 records without holidays or promotions.
* The dataset contains 36,353 records during holidays or promotional events.
* Both categories are almost equally represented.
* The difference between the two groups is very small.

## Business Insights

* Holiday and promotional activities can significantly influence customer demand.
* The balanced distribution allows reliable analysis of promotional impact.
* Holiday and promotion periods can be used as important forecasting features.
* Future analysis can compare sales performance during promotional and non-promotional periods.
