# Category Analysis

## Category Distribution

| Category    | Count |
| ----------- | ----: |
| Furniture   | 14699 |
| Toys        | 14643 |
| Clothing    | 14626 |
| Groceries   | 14611 |
| Electronics | 14521 |

## Findings

* Furniture is the largest category with 14,699 records.
* Electronics has the lowest number of records with 14,521 entries.
* The difference between the largest and smallest categories is very small.
* Product categories are evenly distributed throughout the dataset.

## Business Insights

* Balanced category distribution will help produce reliable forecasting models.
* No single category dominates the dataset.
* Demand forecasting can be performed fairly across all categories.
* Category-level forecasting can be explored in future project phases.
