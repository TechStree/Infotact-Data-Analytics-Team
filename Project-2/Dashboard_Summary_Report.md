# Dashboard Summary Report

## Historical Demand Analysis

* Historical demand remained relatively stable throughout the observed period.
* Daily demand generally fluctuated between 11,000 and 17,000 units.
* No extreme long-term upward or downward trend was observed.

## Category Performance

| Category    | Units Sold |

| Furniture   | 2,025,017  |
| Groceries   | 2,000,482  |
| Clothing    | 1,999,166  |
| Toys        | 1,990,485  |

### Observation

* Furniture generated the highest overall demand.
* Electronics recorded the lowest demand among categories.

## Forecasting Summary

### ARIMA Model Performance

* MAE: 901.61
* RMSE: 1118.03
* MAPE: 6.84%

### Model Selection

ARIMA was selected as the best forecasting model because it achieved the lowest MAE, RMSE, and MAPE values compared to the Moving Average baseline model.

## Business Insights

1. Demand remains consistent across the supply chain.
2. Furniture products require higher inventory allocation.
3. East region should receive priority inventory planning.
4. ARIMA forecasts can support future demand planning.
5. Forecasting can reduce stockouts and excess inventory.

## Conclusion

The dashboard provides business-friendly visualization of demand patterns, forecasting results, category performance, and regional performance. The ARIMA forecasting model delivers reliable demand estimates and can assist inventory optimization decisions.
